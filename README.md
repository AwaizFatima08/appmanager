# App Manager

An Android app by HomiLabs to see and manage every app on your phone: size (app, data, cache), permissions,
install details, and quick actions to open, uninstall (one or many), clear cache and change permissions.

Built with Flutter and a small Kotlin layer. See `CLAUDE.md` for how it works and what Android allows.

```bash
flutter test
flutter build apk --debug
```
